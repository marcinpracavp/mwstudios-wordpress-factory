## Build i wydajność

`npm run build` zachowuje fabryczną konfigurację. `npm run cb:build` używa istniejącego cssnano tylko w jawnej konfiguracji projektu CB; nie zmieniono webpack.config.js ani baseline Figma/Autopilot. Minifikacja nie usuwa używanych selektorów. Główny CSS: 1219580 → 1038200 B, gzip 148546 → 138640 B. Pomiar before assetów pochodzi z nieminizowanego builda po pierwszych drobnych poprawkach; nie zastępuje osobnego screenshot baseline 6f1479c. Dodano cztery oryginalne subsety Poppins 400/600 z istniejącego cache (ich hashe są nazwami plików).

Trzy ostrzeżenia webpack oznaczają przekroczenie rozmiaru assetu CSS, rozmiaru entrypointów oraz wynikającą rekomendację code splitting. Przyczyną jest rozbudowany arkusz factory/bibliotek i CSS wszystkich wariantów źródła CB; sam minifier nie likwiduje ostrzeżeń. Nie obniżono progów ani nie usunięto niesprawdzonych reguł. [Pomiary rozmiarów, największe zasoby i lokalne czasy](TASK-4E-PERFORMANCE.json). Czasy lokalnych równoległych testów nie są wskaźnikami produkcyjnej wydajności.
